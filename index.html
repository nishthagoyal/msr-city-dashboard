How to update the dashboard
1 — Export from SAP
Run your BVA report and save as .xlsx. Run the cost data transaction dump and save as .xlsx. Use the raw SAP export with no formatting changes.
2 — Upload here
Click Upload BVA at the top right and select the BVA file. Click Upload Cost Data and select the transaction dump. Dashboard refreshes instantly.
3 — BVA file format
Standard SAP BVA hierarchical export. Parser reads from row 16, detects WBS codes in cols 3–9 (starting with "WBS BLR-"), Budget in col 13, Actual col 14, Commitment col 15. Values auto-converted from Rupees to Crore.
4 — Cost data format
SAP transaction dump. Auto-detects columns for WBS element (e.g. BLRGDR001SBEX), Partner Object Type, Cost Element, Amount, and posting date. First data sheet is used.
RAG logic
RAG = (Actual + Commitment) ÷ Budget

🔴 Red — deployed >95% of budget  |  🟡 Amber — 75–95%  |  🟢 Green — <75%

Recurring detection (requires cost data file with date column): REC = 6+ posting months, avg gap ≤2 months. SEMI = 4–5 months.

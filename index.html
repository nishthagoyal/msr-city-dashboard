How to update the dashboard
1 — Export from SAP
Run BVA report → save as .xlsx. Run cost data transaction dump → save as .xlsx. No formatting changes needed.
2 — Upload here
Click Upload BVA at top right → select file. Click Upload Cost Data → select file. Dashboard refreshes instantly — no page reload.
3 — BVA file format
Standard SAP BVA hierarchical export (same format as G-Ramaiah_BVA_15_09_2026.xlsx). Parser reads from row 16, Budget col 13, Actual col 14, Commitment col 15. Converts Rupees → Crore automatically.
4 — Cost data format
Standard SAP transaction dump (same format as MSR_actual_cost_data_till_31_3_2026.xlsx). Header on row 2, data from row 3. WBS element col 5, Amount col 9, Posting Date col 2, Dr/Cr col 26, Partner Object Type col 31.
RAG & recurring logic
RAG = (Actual + Commitment) ÷ Budget  |  🔴 >95%  |  🟡 75–95%  |  🟢 <75%

Actuals: D (debit) rows added, C (credit/reversals) subtracted. Rows with blank WBS excluded (SAP summary rows).

Recurring: REC = 6+ distinct posting months, avg gap ≤2 months. SEMI = 4–5 months.

Cost Type: taken from Partner Object Type column. Where VLOOKUP errors exist in the file, derived automatically from WBS code segment (e.g. BR/SD→BROKER, MK→MKTNG, IF→INFRA, CO→CONSUL, CU→CC, FI→FINAN).
